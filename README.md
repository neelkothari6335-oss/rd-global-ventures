# RD Global Ventures Website Starter

Responsive multi-page static website built with HTML, CSS and vanilla JavaScript.

## Pages
Home, About Us, Services, Our Vision, Industries, Dholera SIR, Careers, Contact Us, Privacy Policy, Terms & Conditions, Disclaimer and Cookie Policy.

## Preview
Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish
Upload the complete folder to Netlify, Vercel static hosting, GitHub Pages or your existing web host. Connect your domain and enable HTTPS.

## Before going live
- Replace placeholder social links and add your verified business email/address.
- Replace sample Unsplash images with licensed brand imagery.
- Customize legal pages with professional review.
- Current forms open WhatsApp with prefilled details; they do not save enquiries or send email.
- Career form accepts a resume URL, not an uploaded file. Add secure backend/storage for CV uploads.
- Add only verified Dholera property listings, approvals and project details.
- No backend, CRM, admin dashboard or database is included in this static starter.

## Uploading this updated version to GitHub
1. Extract the ZIP on your computer.
2. Open your GitHub repository and replace the existing website files with the contents of this extracted folder.
3. Upload the complete `assets` folder, keeping its folder structure intact.
4. Commit the changes to the `main` branch. GitHub Pages will redeploy automatically.

## Important GitHub upload instructions
1. Extract this ZIP on your computer.
2. Open your GitHub repository `rd-global-ventures`.
3. Upload the CONTENTS of the extracted folder into the repository root (not the ZIP and not an extra enclosing folder).
4. Keep `index.html` at the repository root and keep the entire `assets` folder beside it.
5. Commit changes to branch `main`. In GitHub Pages settings, use branch `main` and folder `/ (root)`.
6. Wait for deployment, then refresh the website with Ctrl+F5.

The complete website is a static HTML/CSS/JavaScript site. Forms open WhatsApp with prefilled details; they do not store submissions or send email.
